# 尊不住了

纯静态 3D 刹车挑战游戏，支持单人挑战和 2–4 人本地同屏对战。游戏逻辑、计分和音效都在浏览器运行，无需后端或联机服务。

## 本地运行与构建

需要 Node.js 20 或更新版本，无第三方依赖。

```sh
npm run dev
npm test
npm run build
npm run preview
```

开发或预览地址为 http://localhost:5173/ 。构建结果在 `dist/`，将其中的内容部署到静态网站即可。所有资源使用相对路径，支持 GitHub Pages 仓库子目录。请通过 HTTP 地址打开游戏。

## GitHub Pages

1. 上传项目根目录到 GitHub 仓库，使用 `main` 或 `master` 分支。
2. 在 **Settings → Pages → Source** 中选择 **GitHub Actions**。
3. 推送后，`.github/workflows/pages.yml` 会自动测试、构建并部署 `dist/`，也可在 Actions 页面手动运行。

## 玩法

- 自动加速，100 km/h 是起刹门槛，不是限速。
- 按住空格、鼠标左键或触屏加力，松开减力；首次刹车永久切断动力。
- 赛道长 2 km，在路障前停住即成功。车头提前 2.7 米碰撞，因此初始显示约 1997 米。
- 踏板力度达到车型极限会断裂，撞上路障也会失败。初速度越高、刹停用时越短，得分越高。
- 同屏默认键位 P1=A、P2=L、P3=S、P4=K，可修改并支持小键盘。键位和单人最佳成绩保存在浏览器。
- 多人起步共用镜头，拉开后分屏，再次靠近也保持独立，下局重新共享；翻车玩家独立取景，全部收场后结算。
- 同屏物理和绘制共用一个循环，120 Hz 物理按帧插值，镜头跟随车辆，状态栏复用原有元素。

单人点击选车区的车牌即可修改，同屏可分别输入车牌，均保存在当前浏览器。四种车型补充了门缝、饰条和灯组细节；L9 使用更高的 SUV 轮廓及贯穿灯。碰撞按车型设置不同的碎片方向、扩散范围和抛起高度，爆炸时原车身按表面位置拆成 11 个部件，保留原来的车漆、玻璃、灯组和车牌贴图；车门、引擎盖、车顶、尾门、底盘及四个轮胎独立飞散、翻滚和落地。拆分几何在加载时生成并共享缓存，重开后恢复完整模型。L9 参数及全部爆炸效果为游戏设定。

## 车型

| 车型 | 极速 | 踏板耐受 | 游戏制动强度 |
| --- | --- | --- | --- |
| 尊界 V800 | 260 km/h | 1612 N | 10.8 m/s² |
| 尊界 S800 | 210 km/h | 1450 N | 13.0 m/s² |
| 问界 M9 | 200 km/h | 2100 N | 10.6 m/s² |
| 理想 L9 | 200 km/h | 1900 N | 11.8 m/s² |

V800 为原版虚构车型；S800 速度参考纯电星辉尊享版，M9 速度参考 2025 款享六座增程 Ultra。车模、踏板断裂和制动参数为游戏设定。S800、M9 分别采用 1.106、1.432 的计分系数。

## 文件

- `index.html`、`client.js`、`local.js`、`style.css`：入口与界面。
- `shared/`：物理、键位、动态分屏和镜头跟随。
- `assets/`：Three.js 场景、音效及样式。
- `scripts/`：静态预览和构建工具。
- `tests/`：物理、多人操作、分屏及镜头稳定性测试。
